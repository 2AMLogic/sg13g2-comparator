# `sim/comparator-decision-cm-band/`

Decision time, regeneration tau and 0.1 mV resolution (DR-0002 Row 3) at
`dut_vcm` - 50 mV, `dut_vcm` and `dut_vcm` + 50 mV (issue
[#164](https://github.com/2AMLogic/sg13g2-comparator/issues/164)). Evidence for
the DR-0004 candidate input common-mode-range row (#160); **no spec or ratified
record is edited here**, and the bounds used are the unchanged ratified Row 3
Targets (td_od50 <= 1.5 ns, tau <= 250 ps, td_od01 <= 2.0 ns), with the 50 mV
Stretch (0.8 ns) reported.

## Method

The issue #62 `regeneration` bench, unchanged except for the common-mode line,
using the issue #79 mechanism (`sim/kltsim/cmband.py`):
`.param vcm_delta=<d>` and `vcm cm 0 dc {dut_vcm+vcm_delta}` (d = 0.0 for
nominal), recorded in the body header, request (`_condition`) and invocation.
One probe is added (`vcm_meas`, checked against `dut_vcm + vcm_delta` per point).
Request per condition: `engine: ngspice`, `backend: batch`, `mos_tt/ff/ss/fs/sf`
x `vsup = vsupa` 1.08/1.2/1.32 V x -40/27/125 C (45 points), `tran 5p 60n`; the
measurements and limits are those of `20261009-d73a9ac/regeneration.request.json`.
Deterministic bench: no Monte Carlo, so no sigma is claimed. Code:
`sim/kltsim/cmdecision.py`, `sim/run_decision_cm_band.py`, tests
`sim/kltsim/tests/test_cmdecision.py`.

A point is REJECTED (named, with reason, never substituted) if its corner
errored, a supply/temperature/`vcm_meas` probe disagrees with the corner, a
decision-polarity gate failed, or a Row 3 value is missing.

## Reproduce

Use the CI-pinned klt (`0.5.0+ge8ca621a6961`) in a throwaway venv (see
`sim/klt-corner-verification/README.md`); from the repo root:

```bash
S=<series-id>; export KLT_SIM_BACKEND=batch
python3 sim/run_decision_cm_band.py build --series $S
for c in vcm-nom vcm-m050 vcm-p050; do
  python3 sim/run_decision_cm_band.py run --series $S --condition $c --klt .venv/bin/klt --skip-existing
done
python3 sim/run_decision_cm_band.py compare --series $S
```
