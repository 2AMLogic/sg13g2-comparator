# `sim/comparator-offset-cm-band/`

Whole-latch offset (issue [#79](https://github.com/2AMLogic/sg13g2-comparator/issues/79))
at `dut_vcm` - 50 mV, `dut_vcm` and `dut_vcm` + 50 mV, using the issue #62
`offset_mc` bench (strobe-to-decision staircase, mismatch-enabled
`mos_<p>_mismatch`, 5 process x 3 supply x 3 temperature = 45 points,
N = 60 per point) as three paired `klt sim` campaigns on the batch fleet.

**Characterization, not compliance.** DR-0002 ratifies the Offset-sigma row
at `dut_vcm` only, and ratifies no whole-latch common-mode range. The 15 mV
3-sigma Target is quoted as a reference; nothing here is a verdict on a
non-nominal condition, and a binding range needs its own decision record.
The compliance basis stays the nominal record.

## Reproduce

Use the CI-pinned klt (`0.5.0+ge8ca621a6961`, see
`sim/klt-corner-verification/README.md`) in a throwaway venv; from the repo root:

```bash
S=<series-id>
python3 sim/run_offset_cm_band.py build --series $S
for c in vcm-m050 vcm-nom vcm-p050; do
  python3 sim/run_offset_cm_band.py run --series $S --condition $c --klt $KLT --skip-existing
done
python3 sim/run_offset_cm_band.py control --series $S --condition vcm-m050   # mismatch-off (also vcm-nom, vcm-p050)
python3 sim/run_offset_cm_band.py repeat  --series $S --condition vcm-p050 --process mos_tt_mismatch
python3 sim/run_offset_cm_band.py compare --series $S
```

A condition is selected by one `.param vcm_delta` in the netlist body
(`vcm cm 0 dc {dut_vcm+vcm_delta}`; 0 for nominal); it is recorded in the body
header, the request, and every `*.invocation.json` / `attempts.jsonl` entry.
Details: `sim/kltsim/cmband.py`. Pairing: klt derives each draw's seed from
(base seed 20260916, corner index, sample index) only, so draw k at a grid
point is the same mismatch under all three conditions (verified per point in
the comparison, not assumed).

## Evidence

`campaigns/20261009-5185f52/` (append-only): `vcm-*/` hold body, requests,
envelopes, invocations and per-corner artifacts for each condition; `controls/`
holds mismatch-off controls, the same-seed repeat and the abort probe;
`comparison.md` / `comparison.json` are generated by `compare`.
Statistical basis: N = 60 (sigma precision 1/sqrt(2N) = 9.1 %), ratified
quantization-corrected statistic, paired bootstrap for ratios.

Results (see `comparison.md` for every PVT point):

| condition | valid points | clipped draws | 3-sigma min ... max (mV) | grid mean |
|---|---|---|---|---|
| `vcm-m050` (0.55 V) | 43/45 | 0 | 6.89 ... 11.43 | 9.34 |
| `vcm-nom` (0.60 V) | 45/45 | 0 | 6.91 ... 12.09 | 9.51 |
| `vcm-p050` (0.65 V) | 45/45 | 0 | 6.91 ... 12.87 | 9.85 |

- Every valid point is below 15 mV (reference only). Paired 3-sigma ratio to
  nominal averages 0.98 (`vcm-m050`) and 1.04 (`vcm-p050`): a few-percent
  effect, resolved at the paired level for a minority of points.
- Nominal reproduction: `vcm-nom` is bit-identical (2700/2700 draws) to the
  issue #62 campaign `20261009-d73a9ac`. The absolute level differs from the
  DR-0002 harness record by the klt-per-draw vs harness gap tracked in #82.
- Same-seed repeat (`vcm-p050`, `tt_-40c_1.08v`): 60/60 draws bit-identical.
- Mismatch-off controls at all three conditions (`tt_27c_1.20v`): sigma = 0.
- No clipped draws anywhere (range-adequacy gate).
- Per-sample runtime max 3.8 s, inside the point limits.

## Known gaps

Two `vcm-m050` points are REJECTED, not repaired: `tt_-40c_1.32v` (draw
mc12) and `sf_-40c_1.20v` (draw mc23) each have one draw where ngspice's
transient aborts ("timestep too small", node `ibn`) so the measurement errors.
`controls/abort-probe.*` re-runs mc12 with a tighter max step and it
completes (vos = -1.5 mV), but that is a different simulation setting and is
not substituted into the population. Those two points report no sigma (the
59-draw value is informational only). Whether the abort is a bench artifact
or a convergence weakness at the low-CM edge at cold temperature is open.
