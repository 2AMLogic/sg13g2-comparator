# `sim/comparator-kickback-cm-band/`

Kickback **residue** (DR-0002 Row 4, signal-dependent differential residue
against a non-restoring 1 GOhm / 1 pF source) at `dut_vcm` - 50 mV, `dut_vcm`
and `dut_vcm` + 50 mV (issue [#165](https://github.com/2AMLogic/sg13g2-comparator/issues/165)),
as three deterministic 45-point `klt sim` corner campaigns on the batch fleet
(5 process x 3 supply x 3 temperature each, 135 corner runs). Evidence for the
candidate DR-0004 common-mode-range row; **characterization, not ratification**:
no spec bound or ratified record is edited, and the Row 4 residue Target
(<= 100 uV) and Stretch (<= 30 uV) are applied unchanged.

## What is and is not graded

- Graded: `kick_sigdep_uv` at each *valid* point against Target/Stretch. A
  condition with fewer than 45 valid points is `INCOMPLETE`, never `MET`.
- Reported, not graded here: Q_kick per side (`qkick_p_fc`, `qkick_n_fc`,
  `qkick_fc`) and the 1 kOhm peak excursion. The Q_kick sub-bound is already
  NOT MET at nominal (39/45, DR-0003) and is not in the candidate row's hold
  list. The submitted requests keep the original `qkick_fc <= 25 fC` limit, so
  the fleet's aggregate envelope status is `fail` by construction; it is not the
  CM-row verdict. A charge-limit failure never invalidates a point.
- A point is **valid** only if the corner did not error, every measurement is
  reported once and finite, the supply/temperature probes match the corner, the
  new `vcm_meas` probe equals the condition's common mode, and the three
  decision-correctness gates pass. Rejected points are named with their reason;
  nothing is substituted, re-run with a tighter step, or repaired.

## Condition and reproduction gate

The bench is the issue #62 `kickback` bench unchanged except the one source
line `vcm  cm 0 dc {dut_vcm}` -> `.param vcm_delta=<d>` +
`vcm cm 0 dc {dut_vcm+vcm_delta}` (d = -0.05, 0.0, +0.05) and one added probe
`vcm_meas` (`find v(cm) at=5n`). The match tolerates whitespace and must hit
exactly one line (`sim/kltsim/kickback_cmband.py`; this is *not* the offset
bench's `cmband.py` transform, which expects a single space and builds a Monte
Carlo bench). Request measurement cards are emitted in the reference request's
own order. No Monte Carlo, `tran 5p 60n`.

`vcm-nom` is the **reproduction gate**: exact equality of every original
measurement value (and status) against `klt-corner-verification/campaigns/20261009-d73a9ac/kickback`
at all 45 PVT keys, plus identical request (grid, analysis, models, cards,
limits), declared circuit/DUT hashes, engine and model-library hashes. Added
probe and new netlist/invocation metadata are excluded. If it fails, the series
is excluded from DR-0004 evidence.

## Reproduce

Use the CI-pinned klt (`0.5.0+ge8ca621a6961`) in a throwaway venv (not the host
tool); `KLT_SIM_BACKEND=batch` is exported on dispatch hosts. From the repo root:

```bash
S=<series-id>
python3 sim/run_kickback_cm_band.py build --series $S
for c in vcm-nom vcm-m050 vcm-p050; do
  python3 sim/run_kickback_cm_band.py run --series $S --condition $c --klt .venv/bin/klt --retry-refused 10 --retry-wait 60
done
python3 sim/run_kickback_cm_band.py compare --series $S   # offline; exit 2 if the gate fails
```

`build` refuses to change an existing input; `run` refuses to resubmit a part
whose envelope exists or whose `attempts.jsonl` already records a graded run.
A failed batch submit is a reported error, never a local fallback.
